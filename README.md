Entry for the make.fun competition **One Word, One Username, One Reward**
(`u-rusdyxbt-one-word-one-username-one-reward-1a191fae`).

## What it does

`main.py` writes exactly one word to `entry.txt` in the output
directory: the entrant's own make.fun username, `kuroshinne`.
Nothing else — no explanation, no links, no trailing newline.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The output file is created at `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output` is used when the variable is not set).
